# Cinema Arcano — Frontend

Frontend do Cinema Arcano, construído com **Next.js + TypeScript**.

Para a visão geral do produto, decisões de arquitetura e justificativas, ver o [`README.md`](../README.md) e o [`docs/PROJETO.md`](../docs/PROJETO.md) na raiz do repositório.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS

## Rodando localmente

```bash
npm install
npm run dev
```

Aplicação disponível em `http://localhost:3000`.

> Este frontend depende da API do backend rodando em paralelo — ver instruções em `backend/README.md`.
